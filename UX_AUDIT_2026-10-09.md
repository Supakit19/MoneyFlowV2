## UX audit: step, screen, status
1. Login and registration — improved. Labels and touch targets adjusted, authenticated refresh without login flash retained.
2. Dashboard — improved. Empty chart explains what to do, and mobile add-transaction action always has readable text.
3. Transactions — improved. Search result count, no-matches feedback and clear-search action, first-entry empty CTA.
4. Budgets — improved. Distinguishes unset weekly budget from a real remaining 0 THB; first category-budget CTA.
5. Accounts — improved first-use journey via welcome; primary account/opening balance setup.
6. Recurring — improved. Descriptive empty state, first recurring-rule CTA and named delete control.
7. LINE and AI — improved. Replaced developer webhook/API-token instructions with three actions for end users, optional link.
8. Security — improved. Can reopen welcome guide from settings.
9. New-user onboarding — added optional 3-step wizard with accounts, weekly budget/savings and LINE link.

## Data safety and functionality
- Non-destructive addition of users.onboarding_state with existing users default completed.
- Newly registered Google and email users start pending.
- Protected per-user POST /api/onboarding/state only accepts completed or skipped.
- Authenticated PATCH /api/accounts/:id verifies account ownership and safe satang values.
- Weekly spending limit and savings persisted via existing API.
- Tested with separate PostgreSQL database moneyflow_ux_onboarding_check_20261009.
- No changes made to the actual MoneyFlow users or finance records during QA.

## Known limits

- Bundler still warns about an entry chunk over 500KB; optimize lazy loading later if needed.

## How to use
Sign in with a newly registered account and you will see /welcome. Skip any time.
For existing accounts, open /settings and choose the setup-guide action, or browse /welcome directly.
